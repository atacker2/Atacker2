Nobati bot package
==================

Files:
- eliot_bot_updated.py: main bot source
- requirements.txt: third-party Python dependencies

Install dependencies:
    python -m pip install -r requirements.txt

Run (after configuring the required environment variables):
    python eliot_bot_updated.py

Configure secrets such as the Telegram bot token and API credentials in your
host environment (for example, Railway Variables). Do not publish secrets.
